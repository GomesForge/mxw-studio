Import and export

Save the strip, edit it in any paint program, and import it back — a strip exactly as wide as every frame side by side is sliced across all of them. Anything else replaces the current frame, scaled to fit.

The cyan edges are the UV layout of the faces that use this texture — paint inside them. Save the UV PNG as a guide, then drop the finished image back on the page to replace the texture. A GIF that already matches the slot size is stored untouched.

View

Back items sit at negative Z in every file, so +Z is the front. Face frames the head. Choosing a texture never moves the camera — use these when you want to move it.

Geometry

Export, edit the mesh in any modeller, import it back. An OBJ carries no textures, materials bindings or skeleton, so importing into a loaded file keeps those and swaps only the geometry. Coordinates quantise to 16-bit integers and texture coordinates to whole pixels.
