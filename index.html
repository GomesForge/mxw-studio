The cyan edges are the UV layout of the faces that use this texture — paint inside them. A new shape opens as its own file, sized in the same units the meshes use — a body runs about 7090 tall, so 1000 is roughly a hand. Height lifts it off the floor: 4300 is shoulder level, 5600 the head. It has no texture yet; drop an image on it or use Replace texture.

Turns are 90 degrees. Mirroring flips the face winding with the geometry, or the mesh comes out inside out. Coordinates are 16-bit, so anything pushed past ±32767 is clamped and the panel says how much.

For an arm, swing moves it forward and lift raises it; for a leg, swing steps and lift spreads. Twist is the bone's own axis. Measured on the rig rather than guessed.

Keep a pose

The built-in motions are ours; the rig under them is the file's own. An original motion file carries one track per bone, 74 on one body and 75 on the other, which is the shape this player already expects.

Geometry notes

Export, edit the mesh in any modeller, import it back — the buttons are on the bar above. An OBJ carries no textures, material bindings or skeleton, so importing into a loaded file keeps those and swaps only the geometry. Coordinates quantise to 16-bit integers and texture coordinates to whole pixels.

chunks: u32 size + content

Big-endian. A chunk opening "MXW3DHUD" or "MXW3DAVA" is geometry or a skeleton; one opening "GIF8" is a texture. The sprite format is little-endian — the two disagree.

u,v are texture pixels, divided by the size of that material's texture.
