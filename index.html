Geometry

Export, edit the mesh in any modeller, import it back. An OBJ carries no textures, material bindings or skeleton, so importing into a loaded file keeps those and swaps only the geometry. Coordinates quantise to 16-bit integers and texture coordinates to whole pixels.

Format
0x00
"OK  "
0x04
u32 version
0x08
u32 mesh id
0x0C
u32 chunk count
0x10
chunks: u32 size + content

Big-endian. A chunk opening "MXW3DHUD" or "MXW3DAVA" is geometry or a skeleton; one opening "GIF8" is a texture. The sprite format is little-endian — the two disagree.

u,v are texture pixels, divided by the size of that material's texture.
